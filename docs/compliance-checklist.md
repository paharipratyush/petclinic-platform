## Encryption at Rest

| Resource | Encryption | Notes |
|----------|-----------|-------|
| RDS MySQL (prod) | AES-256, AWS-managed key | `storage_encrypted = true` in RDS module |
| RDS MySQL (dev) | AES-256, AWS-managed key | Same — no free-tier penalty for encryption |
| EBS volumes (EKS nodes) | AES-256, AWS-managed key | Set at EC2 account level or via EBS default encryption |
| S3 Terraform state bucket | SSE-S3 (AES-256) | `server_side_encryption_configuration` in VPC module |
| Karpenter SQS interruption queue | SQS-managed SSE | `sqs_managed_sse_enabled = true` |
| Secrets Manager | AES-256, AWS-managed CMK | Default per-secret encryption |
| ECR images | AES-256, default encryption | Scan-on-push enabled |

## Encryption in Transit

| Path | Protocol | Notes |
|------|----------|-------|
| Browser → ALB | HTTPS (TLS 1.2+) | ALB listener 443, cert from ACM |
| ALB → Pods | HTTP (internal VPC) | Acceptable — traffic stays within VPC SG perimeter |
| Pods → RDS | TLS (MySQL SSL mode) | Enforced by `require_ssl = true` in RDS parameter group |
| Pods → Secrets Manager | HTTPS via VPC | AWS SDK uses TLS by default |
| Pods → ECR | HTTPS | Docker pull over HTTPS |
| Pods → Karpenter SQS | HTTPS | AWS SDK uses TLS by default |

## Secrets Management

| Secret | Path in Secrets Manager | Rotation | Notes |
|--------|------------------------|---------|-------|
| RDS master credentials | `petclinic/{env}/rds-credentials` | Manual (see secret-rotation.md) | Auto-generated by Terraform `random_password` |
| OpenAI API key | `petclinic/{env}/openai-api-key` | Manual (rotate at vendor) | Set via `TF_VAR_openai_api_key` |
| Grafana admin credentials | `petclinic/{env}/grafana-admin` | Manual (change after first login) | Set via `TF_VAR_grafana_admin_password` |
| Alertmanager SMTP credentials | `petclinic/alertmanager-smtp` | Manual (rotate at email provider) | ESO-provisioned via ExternalSecret `alertmanager-config` |

**Controls:**

- [ ] No secrets committed to Git (enforced by `.gitignore` + `block-secret-commit.sh` hook)
- [ ] All secrets sourced from Secrets Manager via External Secrets Operator
- [ ] No secrets in Helm values files or K8s manifests
- [ ] ESO refresh interval: 1 hour (automatic rotation pickup)
